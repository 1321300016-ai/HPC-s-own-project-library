# Linux 软件路由器

## 功能

- 基于 Linux raw socket 接收和转发以太网帧。
- IP 黑名单过滤与持久化。
- ARP 缓存、老化清理和并发互斥保护。
- 静态内存池、日志模块、命令行解析和多线程控制。

## 构建

在 Linux 环境执行：

```bash
make
```

运行通常需要 root 权限：

```bash
sudo ./router
```

程序需要预先配置真实的网卡名称、IP 与 MAC 环境；仓库不包含 `.o`、`router` 可执行文件和运行日志。

## 常用命令

在程序命令行提示符下可输入：

| 命令 | 功能 |
| --- | --- |
| `help` | 查看命令帮助 |
| `setip <IP>` | 添加 IP 黑名单 |
| `delip <IP>` | 删除 IP 黑名单 |
| `showip` | 显示 IP 黑名单 |
| `showarp` | 显示 ARP 缓存 |
| `saveset` | 保存黑名单 |
| `exit` | 保存后退出 |
